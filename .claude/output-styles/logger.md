When files are changed then add report to progress_report/<%YYYY_%mm_%dd.log>:

Report should contains sections:
- `goals` short description of changes motivation
- `files` with list of added/removed/edited files with short (max 3 sentences) description of introduced changes
- `dilema` possible section with encountered problems related with chosing most suitable archtectural design/patterns, trade-off related with efficiency, and security.
